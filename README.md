# Primeiro ano da Esther — confirmação de presença

Página estática (GitHub Pages) que envia as confirmações para uma planilha
do Google por meio de um Apps Script.

- `index.html` — a página. A constante `ENDPOINT` aponta para o link `/exec` do Apps Script.
- `apps-script/Code.gs` — código que roda no Apps Script e grava na planilha "Confirmações — Esther".
